# Windows 下载历史合同

## 入口与页面

- 左栏“历史”位于“设置”上方；右侧 QStackedWidget 整页切换，下载工作台实例持续保留。历史页“返回下载”恢复原输入、队列和位置，不创建第二份下载任务状态。
- 历史页按完成日期降序分组，右侧宽度达到 900 逻辑像素时双列，否则单列。搜索、平台、全部时间／近7天／近30天和收藏筛选固定在顶部。
- 封面固定116×84，等比居中裁切铺满、四角10px裁切，播放提示叠加绘制；不使用带灰条的QIcon适配绘制。后台缓存348×252并采用cover-fill-v2标识，不复用旧适配缓存；原媒体不修改。
- HistoryPage 分批查询，每批48条，可加载更多；封面和时长等本地媒体信息由两个后台 worker 按需读取。缓存仅属于本功能的 history-thumbnails，最多保留256张；不清理媒体文件。
- 点击封面在原窗口右侧切换至内置播放器，替换历史列表内容区；不创建QDialog或新顶层窗口，不显示右侧文字／转写栏。历史页居中标题和返回箭头保留。关闭播放或点返回箭头回到同一历史列表，筛选、搜索和滚动位置保留；再次返回才回下载。
- 手机端播放器功能依据当前GitHub源码逐项对齐，具体来源与对照见verification/embedded-player-20261016.md。按用户最新反馈，普通窗口与全屏均可单击画面切换控制栏；左侧30%双击快退10秒，中间40%双击暂停／播放，右侧30%双击快进10秒，同侧600毫秒内继续点击每次累计10秒，反馈800毫秒消失；快进快退保持原播放／暂停状态。
- 顶部原标题／分段文字单行省略与关闭图标，底部播放、快退／快进、进度、时间，均位于黑色播放器内部。普通窗口与全屏播放空闲时控制栏均2500毫秒自动隐藏；拖动进度或操作菜单时保留，缓冲超过350毫秒才出现小型提示；鼠标移动可唤出控制栏。原生视频位于固定40px标题栏与66px控制栏之间，隐藏保留布局尺寸，跳转提示在视频区域正中以不抢焦点、不接收鼠标的透明白字提示显示，仅文字带柔和阴影、不显示黑色底板，800ms自动消失；不占布局，避免原生视频覆盖提示或快进时画面跳动。外框14px抗锯齿圆角，不使用二值窗口遮罩；进度／音量与播放器菜单选中勾号为橙色#f28c28，倍速灰底保持中性。
- 播放进度条与音量条左键点击轨道直接定位对应值，按住可继续拖动，拖动期间控制栏保留显示。
- Windows保留音量／静音、倍速、同窗全屏和键盘操作：Space暂停、左右各10秒、上下音量、M静音、F全屏；Esc先退出全屏，非全屏时返回历史。全屏使用原主窗口，临时隐藏侧栏／页头并去除外边距，退出恢复原窗口状态。
- 多文件记录在播放器控制栏直接选择分段，各文件独立保存位置；音频分段播完自动进入下一段。视频位置每500毫秒检查，变化至少1秒时保存；拖动、切段、失焦、退出即时保存。只有播完才重置，临近结尾仍可续播；加载失败不清空已保存位置。
- 解码失败有中文提示和外部播放器入口；离开历史页或关闭软件释放内置媒体，关闭不影响下载任务。
- 三个筛选入口与手机端语义一致：平台、全部时间／近7天／近30天、视频收藏。平台列出五个受支持站点及已有其他来源；选项为空时如实显示无匹配结果。统一灰底按钮与白色圆角选项面，不使用分裂箭头背景。
- 三点菜单与手机端顺序一致：收藏视频／取消收藏、用外部播放器打开、复制原链接、查看下载报告（仅有真实数据）、分享原链接、删除历史记录。定位文件保留在详情。分享面板提供可复制原链接，不自动发送消息，也不冒称 Windows 系统分享。
- 下载报告仅展示实际采集的传输字节、耗时、速度、连接数和重试数；旧记录无数据就不显示报告入口。

## 数据与所有权

- HistoryStore 是历史归档、查询、收藏、删除和旧队列导入的唯一写者，使用 sqlite3；主窗口只在下载成功回调提交归档。
- 正常运行使用 `%LOCALAPPDATA%/NanfengDownloader/history.sqlite3`；注入 INI 设置的隔离测试／QA 使用同级 history.sqlite3，不连接用户数据库。
- 数据库schema v2仅新增report列，原记录和收藏保留。抖音解析出的原标题／作者通过info_dict传回主窗口；队列、归档及播放器标题使用原始文字，文件系统安全名称另存于输出路径。相同原链接的旧生成占位标题在下一次获取真实元数据时补正，不改已保存的正常标题或媒体文件。
- 保存稳定下载标识、原作品标题、原链接、平台、博主、请求画质、输出文件路径、完成时间与收藏；实际分辨率、时长、大小从本地文件读取，未知不伪造。队列的进度、失败提示和最终文件名不得覆盖原作品标题。
- 归档只接收成功完成且有准确输出路径的下载；失败、取消与已有成品跳过不产生新完成记录。每次开始下载产生新标识，同一标识的重复回调幂等。
- 下载成功且历史归档成功后，立即从下载列表隐藏并从队列持久化中移除，只在历史显示；批次结束再一次性清理内部行，保持线程回传的行号、批次统计和文件定位正确。失败、停止、未选择和已有文件跳过项继续保留。历史写入失败时保留完成项及准确路径，重启恢复时再次尝试归档；不删除媒体。
- archive_receipts 保留已归档标识，删除记录后晚到的重复回调、旧队列导入都不能复活它。新下载使用新标识，可产生新历史。
- 队列恢复仍由 QSettings 拥有。清空队列和关闭“启动时恢复下载队列”不影响独立历史。旧完成队列沿用归档回执去重，恢复时成功归档的完成项不再加入下载列表；输出路径保留，缺失的完成时间显示“较早记录 · 完成时间未知”，不使用文件修改时间推测。
- 收藏限视频，保存指定目标状态；进入收藏时清空搜索、平台、时间条件，随后允许组合筛选。取消收藏不删除历史或文件。

## 删除和文件状态

- 工具区为独立白色搜索栏＋同一行筛选／管理；批量模式右侧原位显示已选数量、取消选择、全选、删除所选，不新增操作行。白卡外侧状态／时间列采用44px固定宽度、78px居中内容组；正常完成为简洁勾号，批量模式同一控件切换选择圆圈，不额外增加复选框。异步媒体探测不改变选择，取消后恢复实际状态。
- 单条／批量删除都需确认，仅删除数据库记录；批量全选作用于当前筛选结果。改变筛选清空选择。
- 文件状态区分存在、部分缺失、确认丢失和暂时无法访问。断开盘符、共享不可用、权限错误等不能归为已删除。
- “清理失效”在后台检查全体记录，仅列出全部输出确认缺失的记录；确认后再次检查再删除记录。部分缺失和暂时无法访问保留。收藏视图隐藏全局清理入口。
- 打开／定位失败显示中文原因；数据库读写失败不冒称保存成功。退出取消缩略图／媒体探测，仅终止并回收本功能直接创建的子进程，不按全局进程名结束程序。

## 验收入口

- tests/test_download_history.py：归档幂等与重启、收藏、搜索字面值、时间／平台筛选、旧记录未知时间、删除不复活、不删除媒体、失效状态、UI导航与批量删除／清理、媒体子进程取消。
- tests/test_download_start.py：实际开始按钮经过Qt线程启动下载边界，切到历史页仍能完成并归档；不得仅用直接调用完成回调替代启动验证。
- tests/test_completed_queue_retirement.py：实际开始按钮与Qt线程验证批次中立即隐藏、后续任务行号稳定、归档失败重启恢复、保留项文件定位及混合结果统计。
- tests/test_queue_persistence.py、test_network_recovery.py、test_queue_single_line.py：队列恢复、部分构造行和标题呈现兼容。
