# 通用网站媒体下载（源码新增，尚未发布）

## 方案选择

- [yt-dlp](https://github.com/yt-dlp/yt-dlp)：复用现有 Python 集成，使用完整站点提取器和 Generic 网页媒体解析；不复制其他项目界面或源码。
- [aria2](https://github.com/aria2/aria2)：负责传输，不负责从普通网页寻找视频。保留当前已验证的加速路径，不对全部网站盲目开启高并发。
- [支持列表](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md)：是引擎支持范围参考，不是本软件逐站实测保证；网站改版、地区、登录和 DRM 均可能影响结果。

## 当前合同

新增合集勾选弹窗：已支持平台返回多个结果时先搜索/勾选，确认后只加入队列，不自动下载。樱花动漫 `/vod/作品ID.html` 和带剧集列表的 `/vod-play/作品ID/ep集数.html` 在智能读取时均展开同作品剧集，按集数排序；媒体直链不展开。勾选后的下载执行仍逐条处理作品页，不递归展开。首页混合多个合集时要求提供具体合集页，不递归全站。默认最多读取500项，继续使用既有加载更多流程扩大读取范围。

实测 `https://yhdm.one/vod/1999457734.html` 返回首批500项，第1至500集。新增筛选、跨站/跨合集过滤和弹窗选择测试。未下载整个合集。

现有六个平台专用路径不变。其他 HTTP/HTTPS 作品页及音视频直链可以直接加入列表，开始下载时交给 yt-dlp 解析。原布局、登录入口和设置保持不变，设置“功能审阅”说明新增能力。

其他网站当前按单条处理：不自动爬取全站或批量下载整个未知集合；包含多条的页面最多处理第一条。批量可粘贴多个具体作品 URL。未知网站不借用已有平台 Cookie，也不使用旧版浏览器 Cookie 配置。输出按来源域名分目录，文件名保留标题及媒体 ID 避免不同作品同名。

这是通用**音视频**下载能力，不把普通网页保存成伪视频，不支持任意 ZIP/PDF、磁力链接或浏览器全网嗅探。付费/DRM/登录限制不绕过。未知网站无产物必须失败，不能因为目录有别的视频就判定已下载。

## 验证边界

定向测试覆盖通用入队、不误用 YouTube、HTTP 入口、凭据隔离、集合限制、无产物失败。真实本地 HTTP 网页嵌入视频经 yt-dlp 下载并通过媒体校验，确认有字节进度和完成事件。

2026-09-09 额外实测 W3C `https://media.w3.org/2010/05/sintel/trailer.mp4`：输出 4,372,373 字节，通过现有媒体校验，收到 4 次包含下载字节的回调。该小样本不构成性能基线。既有平台真实服务未逐一重跑，新增站点也不宣称全部实测。
