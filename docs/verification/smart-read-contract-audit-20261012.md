# 智能读取与当前合同审计

日期：2026-10-12，Windows + Python 3.13；本轮仅本地源码，未重新打包、安装或上传。

## 症状与真实样本

用户反馈抖音智能读取明显变慢，YouTube 正常；提供公开分享链接 `https://v.douyin.com/fnbl_eklrjM/`，对应作品 `7694986028188257599`。样本只做匿名目录读取，未启动媒体下载、未修改用户队列或登录资料。

修复前实际调用：页面读取 0.411 秒 → 重建 opener／重复页面 0.107 秒 → 两个媒体接口失败 → 浏览器媒体嗅探 3.725 秒；总计 4.440 秒。接口的 25 秒超时与浏览器导航／12 秒轮询可叠加，不能把局部 UI 提速当作该网络链路修复。

修复后公开短链三次完整 catalog 调用为 0.523、0.099、0.129 秒，均返回同一个作品链接。Windows 真实按钮 → DiscoveryWorker → 表格一行耗时约 0.187 秒；完整标题／作者／媒体地址延后在下载时获取，列表明确标注下载时解析。

最初原生验收脚本用密集 QTest.qWait 轮询阻碍 Python 工作线程取得 GIL；改为事件处理与 Python sleep 让出执行权后完成真实按钮链路。这是测试等待方式缺陷，没有据此修改应用线程架构。

## 根因与修复边界

1. 读取与下载职责混用：单作品读取调用 _fetch_douyin_info，重复获取页面、接口、媒体。读取改为 URL 身份识别；短链有界请求在已知 Location 提前返回。
2. 作者 ID 污染：URL 与 HTML 拼接的换行被路径正则吞入，导致 API 参数和作者过滤错误。按来源分别提取。
3. 重复采集：作者 API 已合法结束仍启动浏览器；浏览器目标作者结束包后仍进行 24 次 250ms 空轮询。共用结束判据并即时停止；失败、未知或其他作者响应不能冒称完成。
4. 失效短链：主页推荐 ID 不能作为原始作品或作者。只凭明确来源 URL，失效或跳出平台给出错误。
5. 先前本地填表慢点已独立修复：关闭下拉不安装 QApplication 全局事件过滤器；500 行 65.29 → 0.598 秒为离线入表证据。

## 共享下拉验收

combo_box 管理开关与位置，combo_popup 管理表面与行反馈；主窗、设置、选集复用，不从组件反向依赖主窗。按需创建弹层，避免把队列每行变成常驻全局监听者。

Windows 弹层去除原生边框和系统硬投影；白色不透明圆角，16px 透明留边，峰值阴影 alpha≤36，按圆角距离递减；选中淡底和勾选。浅底与深底均核对，无黑边／矩形底板；五项完整可见。重复触发、Esc、方向键／确认和固定下方定位自动验证通过。物理多 DPI、读屏和系统高对比未补造证据。

## 测试隔离

审计发现 7 个旧 UI 测试模块存在不注入设置的 MainWindow()，会复用日常 NativeFormat 配置。已统一转到 tests/ui_fixtures 的独立临时 INI 与临时输出位置，原先显式临时设置的持久化测试保持原 seam。临时根目录在进程退出时清理。未按猜测清理真实队列；实际配置仅做只读计数，观察时原生持久化队列为 0 行，不能据此推断用户窗口的运行时队列或此前状态。
