# UI响应性能优化（2026-10-16，本地源码）

## 已确认热点与修复

- 下载进度每次进入主线程都会重新建立状态、进度、速度、剩余时间等QTableWidgetItem，并同步扫描全部活动队列统计总进度。改为复用单元格、相同内容不重写，总进度最多100ms合并刷新；行内最新值及传输统计仍逐次接收，完成／失败等终态继续即时更新总进度。
- HistoryPage.refresh即使查询结果完全相同也会删除并重建全部卡片。现在保留未变化结果的卡片、封面及滚动位置，仍重置需要清除的批量选择；查询结果变化走原刷新路径。将创建／resize产生的文字省略回调合并为一个Qt零间隔单次定时器。
- 全量回归暴露已有侧栏设置按钮键盘焦点底色缺失，补充同轮廓灰底反馈，保留无内框行为。
