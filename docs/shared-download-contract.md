# 跨平台公共下载规则

当前所有权与验证入口见 [合同索引](contracts.md)。所有平台解析器返回 CatalogItem，统一经过 catalog_rules 去重及导航标题清理，再进入 DiscoveryWorker。单条直接入队；多条使用同一个 CollectionDialog，支持搜索、拖动勾选、逐条/5条/10条分组；确认后只入队。分组不是合并媒体。

读取目录只负责来源身份、已有标题／作者信息与可选择链接，不以可下载媒体流是否存在判定能否入队。YouTube、Pornhub 单条直接入队；抖音明确作品 URL 不发请求，分享短链只完成有界跳转识别，遇到已知作品／作者 Location 即停止，不重复访问反爬页面、请求媒体接口或启动媒体嗅探。无现成元数据时注明下载时解析；下载阶段仍获取真实标题、作者、媒体流并校验输出。失效短链不能用首页推荐内容伪造来源。

抖音作者 URL 与页面 JSON 分源解析；只接受目标作者作品。API 或浏览器目标作者响应明确合法 aweme_list 与 has_more=0 时结束，不再重复启动浏览器或空滚动等待；未知／失败响应保留现有有界回退，不冒称完整目录。B站明确 p= 或剧集只读取指定项；不带 p 的多 P 页面保留分 P 选集。

所有队列任务经过 DownloadWorker → quality_fallback：保留请求画质，明确选择原画质/转码/取消，最终文件由 FFprobe 复核，新文件使用实际短边分辨率命名。未识别尺寸不能伪造画质。既有文件不自动批量改名。

公共交互不等于所有站点都能完整解析。樱花动漫剧集页目前有专用解析器，直接读取页面全部剧集；其他平台仍由各自解析器提供结果，分页继续使用既有加载更多入口。不得把第一页数量或达到上限的结果宣称为完整全站。

全局要求：不递归抓取全站、不混入广告或推荐作品、不自动下载未勾选项。站点适配器只负责来源与作品信息，不各自实现选择弹窗或主界面；界面调整服从用户最新确认的布局。
