# 跨平台公共下载规则

所有平台解析器返回 CatalogItem，统一经过 catalog_rules 去重及导航标题清理，再进入 DiscoveryWorker 的同一个 CollectionDialog。多条结果使用同一弹窗、搜索、拖动勾选、逐条/5条/10条分组；确认后只入队。分组不是合并媒体。

所有队列任务经过 DownloadWorker → quality_fallback：保留请求画质，明确选择原画质/转码/取消，最终文件由 FFprobe 复核，新文件使用实际短边分辨率命名。未识别尺寸不能伪造画质。既有文件不自动批量改名。

公共交互不等于所有站点都能完整解析。樱花动漫剧集页目前有专用解析器，直接读取页面全部剧集；其他平台仍由各自解析器提供结果，分页继续使用既有加载更多入口。不得把第一页数量或达到上限的结果宣称为完整全站。

全局要求：不递归抓取全站、不混入广告或推荐作品、不自动下载未勾选项，不改变主界面布局。站点适配器只负责提供准确作品信息，不各自实现选择弹窗。
