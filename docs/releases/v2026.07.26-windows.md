## 本次更新

- 新增哔哩哔哩和小红书独立登录入口、链接识别、作品列表读取与视频下载。
- 支持将 B站同一 BV 下的多 P 选集展开为独立、可勾选的队列项。
- B站分 P 文件使用 `P01 / P02...` 前缀，避免长标题截断后重名。

- 最终媒体从 FFprobe 元数据校验提升为 FFprobe + FFmpeg 全数据包扫描。
- B站和小红书各完成一个长视频、一个短视频的真实下载验证。
- 49 项自动回归测试通过。
