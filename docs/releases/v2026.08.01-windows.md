# 南枫下载 Windows v2026.08.01

本版本增强下载结果的本地文件操作，并补充链接输入框快速清理功能。

![南枫下载 Windows 界面预览](https://raw.githubusercontent.com/nanzhufeng/NanfengDownloader-Windows/main/docs/assets/nanfeng-downloader-windows-preview.png)

## 本次更新

- 下载完成后，每个队列项目提供独立“定位”按钮。
- 点击“定位”会打开 Windows 资源管理器，并准确高亮该任务对应的视频文件。
- 精准定位使用 Windows Shell 原生接口，支持中文、空格和长文件名。
- 智能读取下方新增“清空链接”，只清空输入框，不影响已经读取的队列。
- 已存在而跳过的文件在能够确定准确路径时，也可以直接定位。
- 54 项自动回归测试通过。

下载 `NanfengDownloader-Windows-v2026.08.01-Setup.exe` 后直接运行。
